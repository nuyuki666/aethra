# Aethra — сайт

Статический сайт: HTML + CSS + ванильный JS, без сборки и зависимостей.
Внешние ресурсы — только шрифты Google Fonts.

## Запуск

```bash
python -m http.server 5177
```

Затем открыть <http://localhost:5177>. Можно открыть и через `file://`, но локальный
сервер предпочтительнее — иконочный спрайт и WebGL-фон ведут себя одинаково в обоих случаях.

## Структура

```
index.html      главная: герой, возможности, активность, тарифы, FAQ
terms.html      условия использования, оглавление со scrollspy
profile.html    личный кабинет: аккаунт / купить ключ / подписка / инструменты
login.html      вход
register.html   регистрация

assets/css/tokens.css   дизайн-токены (3 слоя), reset, базовая типографика, утилиты
assets/css/app.css      компоненты и раскладка
assets/js/icons.js      SVG-спрайт, инлайнится в <body>
assets/js/liquid.js     фон: доменно-искажённый fBm на WebGL + CSS-фолбэк
assets/js/app.js        навигация, reveal, счётчики, график, табы, формы, тосты
```

## Дизайн-система

Токены живут в `assets/css/tokens.css` тремя слоями: примитивы (`--n-*`, `--a-*`,
`--sp-*`) → семантика (`--bg`, `--fg`, `--border`, `--accent`) → компонентные
(`--btn-h`, `--card-*`, `--nav-*`). Менять тему следует на семантическом слое.

- Палитра — холодная нейтральная шкала, фон `#08090b` (не чистый чёрный: на OLED
  он «мажется»). Акцент `--a-500` используется точечно: фокус, активные состояния, данные.
- Шрифты: Inter Tight (заголовки), Inter (текст), JetBrains Mono (числа, метки, ключи).
  Шкала кегля — `clamp()` от 375px до 1440px.
- Движение: 140–420 мс, `cubic-bezier(0.16, 1, 0.3, 1)`.

## Доступность

- Разметка: landmarks, skip-link, видимые `:focus-visible`, тач-цели ≥ 44px.
- Табы кабинета — паттерн ARIA tabs со стрелками, Home/End и синхронизацией с хешем URL.
- Точки графика доступны с клавиатуры и подписаны через `aria-label`.
- `prefers-reduced-motion` отключает анимации и переводит фон в один статичный кадр.
- Без WebGL фон деградирует в CSS-градиенты; без JS остаётся читаемая статика.

## Что здесь замокано

Бэкенда нет. Формы валидируются на клиенте и показывают тост вместо запроса,
чат в кабинете наполняется из локального массива, цифры активности — демонстрационные.
Точки подключения: `initForms()` и `initChat()` в `assets/js/app.js`.
